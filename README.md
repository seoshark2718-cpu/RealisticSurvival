# RealisticSurvival 플러그인

Paper/Spigot 1.20.4용 생존 현실성 플러그인입니다.

## 빌드 방법

1. [Java 17 이상](https://adoptium.net/)과 [Maven](https://maven.apache.org/download.cgi)을 설치하세요.
2. 이 폴더에서 터미널을 열고 아래 명령어를 실행하세요.

```bash
mvn clean package
```

3. 빌드가 끝나면 `target/RealisticSurvival.jar` 파일이 생성됩니다.
4. 이 jar 파일을 서버의 `plugins` 폴더에 넣고 서버를 재시작(또는 리로드)하세요.

> 참고: 이 코드는 Anthropic 컨테이너 환경(네트워크 차단)에서 작성되어 자동으로 컴파일 테스트를 하지 못했습니다.
> Maven이 PaperMC 저장소에서 `paper-api`를 내려받으므로, 처음 빌드할 때는 인터넷 연결이 필요합니다.
> 문법 오류가 있다면 `mvn clean package` 실행 시 에러 로그를 알려주시면 바로 고쳐드릴게요.

## 포함된 기능

### 생존 시스템
- **체온**: 바이옴/시간대/날씨/수중여부/열원 근접 여부에 따라 변화, 보스바로 표시, 저체온증 시 지속 피해
- **무게**: 인벤토리 내 아이템 종류별 가중치 합산, 과적재 시 이동속도 감소
- **부상/출혈**: 몹에게 맞으면 확률적으로 출혈, 방치 시 감염, 붕대(지혈)/약초(완치) 아이템으로 치료
- **수영**: 장시간 수영 시 피로(채굴 속도 저하), 찬물에서 체온 추가 하락

### 날씨/재난
- 비 오면 이동속도 소폭 감소
- 랜덤 재난: 폭우 / 지진 / 해일 / 폭설 / 가뭄 / 산불 (강도 매번 랜덤, 발생 전 전조 메시지)
- 관리자 명령어 `/재난 <종류>` 로 테스트 발동 가능

### 몬스터 (게임 시작부터 등장)
- 바닐라 좀비/스켈레톤 등 자연 스폰 차단, 커스텀 몬스터로 대체
- 무기 기본 장착, 종족(species)이 다르면 몬스터끼리도 서로 적대
- 햇빛에 타지 않음
- 플레이어가 먼저 공격하기 전엔 공격하지 않음(반격형)
- 체력이 낮아지면 겁쟁이形은 무기를 버리고 항복

### 적대 세력 (인게임 150일 이후)
- 세력별(철혈단/그림자단) 다른 갑옷·무기 세트
- 플레이어를 먼저 발견하면 추적 + 전투 시작
- 150일 이후 시간이 지날수록 등장 빈도 점진적 증가 (상한 있음)
- 거점과 너무 가깝지 않은 거리에서 스폰, 서버 전체 최대 개체수 제한
- 300일 이후 드물게 우두머리(보스)급 개체 등장, 처치 시 서버 전체 알림
- 청크 언로드 시 자동 디스폰(성능 보호)

### 명령어
- `/룰` - 생존 안내 및 팁
- `/생존정보` - 자신의 체온/부상/일수 확인
- `/재난 <폭우|지진|해일|폭설|가뭄|산불>` - (관리자) 재난 강제 발동

### 설정
`config.yml`에서 대부분의 수치(체온 임계값, 재난 확률, 세력 스폰 빈도 등)를 조절할 수 있습니다.

## 참고 - 리소스팩
붕대/약초는 현재 기존 텍스처(양털, 고사리)를 재활용해 이름표로 구분합니다.
전용 텍스처를 원하시면 리소스팩을 따로 제작해서 `CustomItems.java`의 Material을
커스텀 모델 데이터가 붙은 아이템으로 교체하면 됩니다.

## 확장이 필요한 부분 (설계는 되어있지만 단순화된 부분)
- 협상(음식으로 몬스터 일시 우호화), 정보원 몬스터 등 세부 상호작용은 현재 미구현이며,
  MonsterManager의 onDamaged/onTarget 로직을 확장해 추가할 수 있습니다.
- 세력 본거지(캠프) 시스템은 미구현입니다. FactionManager에 거점 좌표 저장 + 주변 스폰 로직을 추가하면 됩니다.
- 가뭄/산불은 대량 블록 순회로 인한 서버 부하를 피하기 위해 확률 기반의 가벼운 연출로 단순화했습니다.
